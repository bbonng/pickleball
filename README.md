# 피클볼 수업 나눔 — GitHub Pages용 폴더

2026. 10. 8. 중등체육교육연구회 연수 (대구일중 테니스장)

## 폴더

- `index.html` — 수업 나눔 (QR로 여는 첫 페이지)
- `eval/index.html` — 평가 모션그래픽 (마지막 "공간" 글자를 2.5초 안에 다섯 번 두드리면 이 페이지로 넘어감)
- `book/index.html` — 수업나눔 에세이 (휴대폰으로 넘겨 읽는 책, 7장 + 부록)
- `read/index.html` — 읽기 자료 「피클볼이란?」 (자료 맨 위 카드에서 연결)
- `photo/`, `*.jpg`, `class3y.mp4` — 사진, 답안지, 시험지, 수업 영상

파일 이름과 폴더 구조를 바꾸지 마세요. 두 페이지가 서로를 이 경로로 찾습니다.

## 올리는 법

1. GitHub에서 새 저장소를 만듭니다. 예: `pickleball` (Public)
2. 저장소 화면의 **Add file → Upload files**에 이 폴더 **안의 내용 전부**를 끌어다 놓고 Commit
   (폴더째가 아니라 `index.html`이 저장소 맨 위에 오게)
3. **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 두고 Save
4. 1~2분 뒤 `https://bbonng.github.io/pickleball/` 에서 열립니다. 이 주소로 QR을 만듭니다.

## 연수 끝난 뒤

학생 답안지와 수업 사진이 공개된 채로 남습니다. 내릴 때는 저장소 **Settings → Pages**에서 끄거나 저장소를 Private로 바꾸면 됩니다.
